# ESPocket

**ESPocket is a lightweight application platform for ESP-powered smart devices, built on ESP-Brookesia.**

ESPocket 负责产品语义、系统装配和交互契约；ESP-Brookesia 提供 App、Runtime、Service、GUI 与设备框架。V0.x 面向 Waveshare ESP32-S3-Touch-AMOLED-1.75C，但平台不等同于该硬件或 Circular Shell。
