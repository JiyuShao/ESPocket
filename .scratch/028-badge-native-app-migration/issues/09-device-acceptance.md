# 09 — 真机玩法与无线验收

**What to build:** 在 Waveshare 1.75C 与 macOS/Windows 主机验证七个 App 的真实交互、生命周期、IMU、无线共存与资源回收。

**Blocked by:** [08 构建候选](08-offline-build-candidate.md)，设备及目标主机可用，取得本次刷写/配对/实际 HID 测试授权。

**Status:** ready-for-human

- [ ] 固件对应 08 候选 identity，记录设备、主机系统及测试输入；独立取得刷写与实际输入测试授权，不继承其他会话的部署授权。
- [ ] 六个游戏/玩具分别验证触摸、玩法、视觉、中文与音效；实际 IMU 轴向、采样/漂移/唤醒和不可用路径获得硬件证据。
- [ ] 七个 App 分别走 Quick Settings→返回、息屏→唤醒、覆盖→息屏→亮屏→收起、PWR Home→重开；进度按同次实例恢复，Home 后 Root，不误输入或复活旧页面。
- [ ] 每个 App 连续打开/停止十次，记录资源回收与错误；不能出现遗留采样、timer、音效、HID 或旧实例回调。异常留票，不凭“看起来正常”判为完成。
- [ ] macOS/Windows 分别验证首次配对、重连、失败重试、主机切换、设备管理/忘记配对、按电脑灵敏度，以及触控板/空中鼠标移动、点击、拖动、滚动。
- [ ] 遥控覆盖释放输入但保留连接，息屏/Home 释放并断开；恢复不补发旧输入。传感器校准/失效不造成漂移或持续鼠标运动。
- [ ] Wi-Fi 保持开启，实际聊天/联网与 BLE 遥控共存时记录 UI 响应、连接表现、资源和输入延迟；不静默关闭网络。性能不足保留 blocker 并依据测量讨论，不虚设已达标数值。
- [ ] 遥控实际操作计为活动、闲置按系统超时息屏、主动息屏优先，动画不保持亮屏；现有聊天/计算器/Settings、键盘、对话框恢复无回归。
- [ ] 将每条通过、失败和未验证事实写入 records；只有全条件满足才关闭本票及 Effort。
