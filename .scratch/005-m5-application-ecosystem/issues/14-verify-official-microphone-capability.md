# 14 — 验证官方小智音频能力与本机麦克风

**What to build:** 核实官方录音、编码、小智传输实现的来源，使用独立临时固件验证本机麦克风与 I2S 采样，恢复现有产品镜像并记录结论。

**Blocked by:** 无；端到端小智对话不属于本票验收。

**Status:** resolved

## Scope

2026-10-07 用户在确认“是否官方自带能力”后授权验证。临时诊断可以启用录音，但不改变产品的 playback-only 配置，不写入 NVS 或文件系统，不上传或保存音频正文；只输出采样统计。沿用现有 App-only 刷写、保留用户数据、完成后本地合并和清理任务 worktree 的授权。

## Acceptance

- [x] 核实锁定官方组件中的录音、编码与小智音频收发实现。
- [x] 根据厂商原理图与示例核对录音芯片、麦克风及引脚。
- [x] 真机验证芯片响应、有效采样和受控声音响应；明确物理及端到端限制。
- [x] 校验当前镜像备份，诊断后恢复同一镜像并验证启动、Home 与 App。
- [x] 将镜像身份、测量、失败和未验证项写入日期记录，Markdown 检查通过。

## Resolution

2026-10-07：官方实现来源核对、独立构建和两个麦克风的三轮受控短音采样通过，原镜像 `0203fb1fc` 已恢复，Launcher／AI Chatbot／Home 正常。恢复后服务器确认激活成功，实际会话仍因当前产品缺少 AudioEncoder0 而失败；未宣称语音对话通过，正式录音配置未改变。首次长读取备份失败、覆盖区域备份与恢复校验、样本统计及后续接入边界见[验收记录](../records/2026-10-07-official-microphone-verification.md)。280 份 Markdown 与 diff 检查通过，验证范围完成。
