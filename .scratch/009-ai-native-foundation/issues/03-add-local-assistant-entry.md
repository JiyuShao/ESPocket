# 03 — Add a local Assistant entry

**What to build:** A system-controlled, single-turn local entry that can map a confirmed user goal to the brightness semantic Action without selecting a network or voice Provider.

**Blocked by:** 02 — Build the brightness semantic adapter.

**Status:** ready-for-agent

- [ ] A direct brightness goal can be executed and reported.
- [ ] An ambiguous goal such as “I cannot see” requests clarification before any Action.
- [ ] The entry remains responsive to PWR and has no model/network dependency.
- [ ] The UI is the smallest real product entry and does not prebuild a general Overlay framework.
