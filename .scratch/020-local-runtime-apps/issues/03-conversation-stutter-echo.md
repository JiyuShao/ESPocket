# 03 — 连续聊天卡顿与回复尾音自触发

**What to build:** 修复本地聊天的回复尾音重新输入与连续对话声音／页面卡顿，保持真实 Agent／Audio／GUI Owner。

**Blocked by:** 无授权阻塞。用户已明确授权测试；连续卡顿根因与实际声学回归仍待设备证据。

**Status:** ready-for-agent

## Acceptance

- [x] 用户明确卡顿与静音自触发症状；实际代码路径主机复现并保存结果。
- [ ] 回复结束以真实播放完成边界控制半双工上传，旧采集帧不被作为新输入发送。
- [ ] 无人说话的回复后静音窗口不产生下一轮 User 输入，真实声学回归通过。
- [ ] 连续对话卡顿有量化复现、根因与对应回归；声音及触摸响应正常且资源有界。
- [ ] Owner 回归、统一 host checks、完整构建与真机验证通过，记录未验证项。

## Comments

用户确认安静时也会自动继续回答，声音断续同时页面卡顿。主机已复现远端 speech stop 后仍在播放的尾音可经过上传门禁；10,000 条消息的 JS 合成压力下仅保留 10 个消息／View，不能据此宣称真实 GUI 或音频稳定。准确代码边界、命令与限制见[诊断记录](../records/2026-10-07-conversation-stutter-echo.md)。
