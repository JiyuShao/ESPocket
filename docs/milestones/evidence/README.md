# Milestone Evidence

这里保存被 Milestone 验收文档引用的原始构建、串口、交互和诊断记录。

## 规则

- 已引用文件视为不可变；不要压缩、格式化或覆盖。
- 文件名保留阶段、场景和日期，便于离线核对。
- 凭据、SSID、密码、私钥和其他敏感值不得进入证据。
- 失败记录与成功记录同样保留，并在验收文档中明确其证明边界。
- SHA-256 与结论写在验收文档中，不在原始记录里追加说明。
