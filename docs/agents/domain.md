# Domain docs

探索或修改领域前，按顺序阅读：

1. 根目录 `CONTEXT.md`，获取规范 ESPocket 术语。
2. `docs/adr/` 中与本次变更相关的约束性决策。
3. `docs/README.md` 指向的产品契约或架构视图。

在 Spec、ticket、测试和面向代码的提案中使用 glossary 术语。如果提案与已接受 ADR 冲突，必须指出该 ADR 并显式重新打开决策。

ESPocket 使用单一 context。`CONTEXT.md` 只定义术语，不承载实现状态、源码路径或设计理由。ADR 解释长期选择，当前工作位于 `.scratch/`。
