# Triage labels

| Matt role | Local `Status:` | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must decide disposition. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | An agent can execute the ticket from its acceptance criteria. |
| `ready-for-human` | `ready-for-human` | The next step requires a person or physical device. |
| `wontfix` | `wontfix` | The repository will not pursue the work. |

Historical reconstruction uses `retrospective-resolved`; a reconstructed effort with remaining current work uses `retrospective-active`. These are record statuses rather than triage roles.
